# Что можно сказать ассистенту

Все фразы ниже распознаются **офлайн** (они входят в набор тестов маппера `Ru2Zh`). Зона по умолчанию —
место говорящего: «подогрей сиденье» с водительского места греет сиденье водителя, с заднего правого —
заднее правое. Зону можно назвать явно: «пассажиру», «сзади слева», «заднему правому», «все».
Числа можно говорить словами («на двойку», «двадцать два»).
